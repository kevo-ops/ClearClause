Privacy Policy for ClearClause

Effective Date: 5/27/2025

ClearClause ("we", "our", or "the Extension") is a Chrome extension that helps users quickly understand privacy policies by summarizing them in a clear, concise format.

We take your privacy seriously. This Privacy Policy describes what data we collect, how it is used, and how we handle your information.

1. Information We Collect

We do not collect any personally identifiable information. The only data we access is:

  • The visible text content of the webpage currently open in your browser tab when you activate the extension.

2. How We Use This Information

The text content of the active webpage is:

  • Sent securely to a third-party summarization API (RunPod) for processing.

  • The summary is then displayed locally in a modal window on the same page for your convenience.

We do not store or log any of the content processed through the extension.

3. Third-Party Services

We use RunPod to process and summarize webpage text. RunPod may temporarily receive and process content you submit for summarization. Please refer to RunPod’s privacy policy for more details on their data handling practices.

  • RunPod Privacy Policy

We do not control or retain any data once it is sent to the summarization API.

4. Permissions

This extension requests the following Chrome permissions:

  • activeTab – to access content of the tab you choose to summarize.

  • scripting – to extract and inject content as needed.

  • tabs – to identify the active tab.

  • host permissions – to run the extension on any website when invoked.

These permissions are used strictly to enable summarization functionality and are only activated when the user interacts with the extension.

5. Data Security

We use secure HTTPS connections to transmit data to the summarization API. No data is stored locally or remotely after the summarization is complete.

6. User Control

The extension does not run automatically. It only activates and sends content for summarization when you manually trigger it. You are always in control.

7. Changes to This Policy

We may update this policy as needed. Changes will be posted on this page with a revised "Effective Date."
